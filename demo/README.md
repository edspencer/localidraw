# demo

A neutral folder of canvases, for the README's GIF and for trying Localidraw out:

```sh
npx localidraw demo
```

Two projects, `web-app` (an architecture sketch and a login flow) and `notes` (some sticky notes). Nothing in it is
real. `npm run docs:media:demo` remakes it ([tools/docs-media](../tools/docs-media/README.md)).
