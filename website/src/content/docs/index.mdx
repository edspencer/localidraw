<CardGrid>
	<Card title="Projects and canvases" icon="open-book">
		Every folder with `.excalidraw` files in it is a project, and each file is a canvas, in a **Canvases** tab
		next to Excalidraw's Library. [The sidebar](/canvases/)
	</Card>
	<Card title="Saved as you draw" icon="document">
		Each canvas is written back to its file a moment after you stop. Opening one, or moving around it, never writes
		it, so `git status` stays clean. [Saving and merging](/saving-and-merging/)
	</Card>
	<Card title="Draw alongside your agent" icon="rocket">
		When an agent edits a file you have open, the change appears within a second, merged per element with what
		you've drawn. [Working with coding agents](/agents/)
	</Card>
	<Card title="It's Excalidraw" icon="star">
		Excalidraw 0.18.1, the version the VS Code extension uses, so files open in both. It runs offline, on
		127.0.0.1 only.
	</Card>
</CardGrid>
