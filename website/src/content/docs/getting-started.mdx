import { LOCAL_URL, DEFAULT_PORT } from '../../site.mjs';

You need [Node.js](https://nodejs.org) 22 or later. Nothing else: Localidraw has no runtime dependencies, and the
editor and its fonts are in the package.

```sh
npx localidraw            # the current folder
npx localidraw ~/notes    # or any folder
```

Then open <a href={`${LOCAL_URL}/`}>{LOCAL_URL}</a>. It prints the address, the folder and how many canvases it found, and what it listens on:

```
Localidraw 0.4.0: http://localhost:3729/
  /Users/you/notes (4 canvases)
  listening on 127.0.0.1:3729 (this machine only)
  answering to localhost
  watching for changes by file events
```

To keep it around rather than download it each time, install it globally:

```sh
npm install -g localidraw
localidraw ~/notes
```

## Options

```
localidraw [serve] [folder] [--port <n>] [--open] [-q] [--host <addr> --allowed-host <name>] [--poll [ms]]
```

| Option | What it does |
| --- | --- |
| `serve` | Runs it in the foreground. It's the default, so `localidraw ~/notes` is the same as `localidraw serve ~/notes`. |
| `folder` | Where the canvases are. The default is the current folder. `node_modules` and dot-folders (`.git` and the like) are skipped. A folder with a command's name (`serve`, `service`, `update`, `busy` or `doctor`) is given as `./service`: the command wins. |
| `service <command>` | Runs it in the background from login on, serving one folder: see [Running as a service](/service/). |
| `busy [--json]` | Says whether the Localidraw running here is in the middle of a save: exits `0` (no), `75` (yes) or `3` (nothing's running). For scripts, before a restart. |
| `update` | Updates it to the latest version, and restarts the service: see [Updating](/updating/). |
| `doctor` | Checks that it can run here, with a fix for anything that's wrong: see [Updating](/updating/#when-something-is-wrong-doctor). |
| `--port <n>` | The port. The default is <code>{DEFAULT_PORT}</code>, which spells "DRAW" on a phone keypad, or `$PORT` if that's set. |
| `--open` | Opens it in your browser. |
| `-q`, `--quiet` | Prints only the first line, `Localidraw <version>: <url>`, for a script that wants the URL. Hosted, the warning that Localidraw has no login still goes to stderr. |
| `-v`, `--version` | Prints the version. |
| `-h`, `--help` | Prints the options. |

These are for [hosting it](/self-hosting/), on a server or in Docker, behind a reverse proxy:

| Option | What it does |
| --- | --- |
| `--host <addr>` | The address to listen on. The default is `127.0.0.1`, or `$LOCALIDRAW_HOST` if that's set. Anything that isn't loopback (`0.0.0.0`, a LAN address) needs at least one `--allowed-host`, or it won't start. |
| `--allowed-host <name>` | A host name to answer to besides localhost, such as `draw.example.com`: the name alone, without `https://` or a port. Repeat it for more, or set `$LOCALIDRAW_ALLOWED_HOSTS` to a comma-separated list. Requests for any other name are refused. |
| `--poll [ms]` | Finds changes by checking the files every `ms` milliseconds (2000 if you leave it out) instead of by file events. For a folder on a network mount (NFS, SMB) or a Docker Desktop bind mount on macOS, where the writes send no events. `$LOCALIDRAW_POLL` takes the milliseconds, or `true`. |

A flag wins over its environment variable, and `--allowed-host` flags replace `$LOCALIDRAW_ALLOWED_HOSTS` rather
than adding to it.

If the port is taken, it says so and stops; run it with `--port` and another number. One Localidraw per folder: two
servers on the same folder would each save without knowing about the other's page.

## Stopping it

Press <kbd>Ctrl</kbd>+<kbd>C</kbd>. It stops taking requests, lets any save under way finish writing (for up to five
seconds), and exits. `docker stop` and a service manager send SIGTERM, which does the same. On Windows, which has no SIGTERM,
<kbd>Ctrl</kbd>+<kbd>Break</kbd> does too, and so does the message `"stop"` from a Node process that started it with an IPC
channel. A save the page tries
after that is kept on the page, which says "Not saved" until the server is back. Press <kbd>Ctrl</kbd>+<kbd>C</kbd>
again to stop at once.

| Exit code | When |
| --- | --- |
| `0` | It stopped on <kbd>Ctrl</kbd>+<kbd>C</kbd> or SIGTERM, or `--help` or `--version` printed. |
| `1` | It failed: the port is in use, the page isn't built, or a save was still under way after five seconds. |
| `2` | A usage error: an unknown option, or a bad value. The usage follows the message. |

These follow the [CLI contract](https://github.com/edspencer/cli-contract) that Ed's local tools share.

While it runs, it writes `~/.localidraw/runtime.json`, which says where it's listening, and removes it when it stops.
To keep it running in the background instead, see [Running as a service](/service/).

## What it remembers, and where

- **The drawings are the files.** Nothing else is written into them: no viewport, no theme, no sidebar state.
- **The browser keeps your preferences:** the viewport per canvas, the theme and whether the sidebar is docked, in
  `localStorage`. They follow the browser, not the folder. So does Excalidraw's Library, unless the folder has a
  [`library.excalidrawlib`](/library/) to share it in.
- **The open canvas is in the URL**, as `?canvas=path/in/folder.excalidraw`, so you can bookmark one.

## Safety

Localidraw listens on `127.0.0.1`, so nothing else on your network can reach it. It refuses requests whose `Host` or
`Origin` isn't localhost, so a web page you visit can't read or write your canvases through it. Hosting it is
something you turn on, by name: see [Self-hosting](/self-hosting/).

It only touches `.excalidraw` files inside the folder you gave it, outside dot-folders and `node_modules`, and the
folder's `library.excalidrawlib` if you made one. It creates, saves, renames and moves canvases, never over another file, and never deletes one: deleting from the
sidebar moves the file into `.localidraw/trash/` in the folder.
