Rename, move and delete canvases from the sidebar: each canvas has a menu (its ⋯ button, or a right-click). Rename or move edits the canvas's path in place and never replaces another file; the open canvas is saved first and the page follows it. Delete asks first, and never deletes anything: the file moves into `.localidraw/trash/` in the folder, and **Undo** puts it back.
